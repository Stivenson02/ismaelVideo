# Planes de producción

Guardar un plan por historia como `docs/plans/<HIST-CODE>-plan.md`, por ejemplo `HIST-001-plan.md`. El índice `docs/episodes/INDEX.md` relaciona el código, nombre y documento de cada historia.

La skill de planificación solo crea un plan si el brief del episodio está en `ready-for-plan`. Debe usar la historia y el guion aprobados, el checklist de recursos, `docs/DIRECCION-VISUAL.md`, los spikes pertinentes y el estado actual del código.

El plan define objetivo de entrega (`animatic` o `video-final`), tareas ordenadas, archivos afectados, dependencias, criterios de aceptación, riesgos y revisión prevista. **No contiene ejecución ni marca el episodio aprobado.** La skill ejecutora recibe el plan después de la aprobación de la persona.
