# Bandeja de ideas

Una idea por archivo: `docs/ideas/<slug>.md`.

Esta carpeta conserva lo que la persona quiere explorar antes de investigar o convertirlo en historia. La skill de ideas/historia puede enriquecer la ficha, pero debe conservar la idea original para no cambiar su intención.

## Ficha

```md
# <Título corto>

**Estado:** inbox
**Fecha de ingreso:** YYYY-MM-DD
**Origen:** idea personal | pasaje bíblico | experiencia | referencia

## Idea original

<Texto original, sin reescribir>

## Referencia aportada

<Pasaje, Biblia/traducción, archivo o enlace; si no hay, indicar “por investigar”>
```

Estados permitidos: `inbox`, `researching`, `story-draft`, `story-approved`, `archived`.
