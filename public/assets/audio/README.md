# Audio local

Carpeta para voces grabadas o pruebas locales de síntesis y notas de pronunciación. HIST-001 tiene una voz TTS de referencia; la voz final sigue pendiente.

El archivo `sfx/mixkit-orchestral-happy-prompt-636.wav` es el sonido elegido para el cierre recurrente de marca. El original dura 4,05 s y se conserva intacto. La copia de uso es `sfx/ismael-outro-sting.wav` (2,90 s, salida coseno desde 2,30 s), que reproduce la placa común. Fuente: Mixkit, [licencia de efectos gratuitos](https://mixkit.co/license/modal/sfxFree/).

Kokoro.js no se instala como narrador del episodio en español: la ficha del modelo consultado solo enumera voces en inglés estadounidense y británico. Piper es un candidato a evaluar porque su catálogo incluye voces españolas; antes de elegir una hay que escuchar muestras y revisar la licencia del modelo concreto.
